CREW · crew.pac-run.com
러닝 크루 기록 · 이벤트 · 관리 통합 플랫폼  개발 중

조직 계층

1차 기수 (generation) → 1기, 2기, 3기... 2차 지역 (region) → 반포·연대·인천·군포 3차 조 (group) → A조/B조... (5~15명) 4차 등급 (grade) → A/B/C 자동 매칭 5차 훈련그룹 → S/1~7조 (선택) A조→120km B조→100km C조→80km

러닝 이미지 파싱 플로우

1
이미지 업로드AJAX POST /running-logs/parse-image
2
AI 파싱CORE → S3 업로드 → Claude Vision → JSON 리턴
3
Draft 저장createDraft() → is_confirmed=false
4
사용자 확정결과 확인·수정 → POST /running-logs/{id}/confirm
5
관리자 검수Filament /admin → is_confirmed=true → 마일리지 반영

완료 기능

  • 초대 코드 기반 가입 (클로즈 베타)
  • crew 스키마 전체 마이그레이션
  • 러닝 이미지 2단계 파싱 플로우
  • 다중 이미지 일괄 업로드 + batchConfirm
  • 기록 삭제 시 S3 자동 삭제
  • EC2 배포 + Nginx HTTPS
  • Filament v4 완전 어드민 (15+ 리소스)
  • 기수 신청서 (동적 폼 빌더)
  • Google Forms 연동
  • 포토갤러리 / 공지사항 / 회의록
  • 버그 제보 시스템
  • 이벤트 CRUD + A타입/B타입
  • 단체 문자 (솔라피 + 웹훅 상태 추적)

다음 작업 (우선순위)

  • 이벤트 목록 페이지 (/events)
  • 개인 / 조별 기록 조회 뷰

아키텍처 패턴 & 보안
Controller → Service → Model 3계층 + 필수 보안 체크리스트

3계층 아키텍처

Controller app/Http/Controllers/ 요청 수신 → validate() → Service 호출 비즈니스 로직 작성 금지 ↓ Service app/Services/ 비즈니스 로직 전담 · 데이터 정제 여러 Controller에서 재사용 가능 ↓ Model app/Models/ 단순 CRUD → Eloquent ORM 복잡 JOIN/집계 → DB::select() raw 재사용 쿼리 → scope / static 메서드

기능 추가 표준 절차

1
Modelfillable, casts, scope 정의
2
Migration기존: Schema::table / 신규: Schema::create
3
Service비즈니스 로직, Model 호출
4
Controllervalidate → Service → 응답
5
ViewBlade + Tailwind CSS

보안 체크리스트

항목규칙
API 키.env 관리 · Git 금지 · 로그 노출 금지
운영 환경APP_DEBUG=false · Swagger 비활성화
CSRF모든 POST/PUT/DELETE에 @csrf 필수
관리자/admin/* → auth, verified 미들웨어
입력$request->validate() 필수
개인정보이름/이메일/전화 → AES-128 암호화

개인정보 암호화 설계

데이터방식컬럼

이메일 (표시)AES-128 양방향email_enc
전화번호AES-128 양방향phone_enc
이름AES-128 양방향name_enc
