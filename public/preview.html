날씨 × AI 시스템 · 기획 완료 / 설계 대기
"숫자가 아닌 상황 해석을 주는 마라톤 특화 날씨 서비스" — PLAN-weather-ai-idea.md 기준

날씨 예측 3단계 전략

가까운 미래 (3일 이내) → 기상청 단기예보 API 정확도 높음 중간 거리 (1~2주) → 기상청 중기예보 API 먼 미래 (한 달 이상) → 5개년 평년 데이터 기반 AI 예측 레이스 시간대 오전 6시~오후 2시 최근 연도 가중치 높음 (이상기후 반영)

날씨 더블체크 전략

경로 1. 기상청 ASOS API → 공식 측정소 기온/습도 (시내 고정 위치) 경로 2. 사용자 이미지 파싱 → 코스 현장 실측 (호수·강변 등) → 데이터 축적 시 코스별 보정값 자동 생성 "춘천 코스: 기상청 -1.2°C / 습도 +8%"

날씨 해석 메시지 예시

⚠️ 습도 95% — 체감 온도보다 체력 소모가 큽니다. 평소 페이스보다 10~15초 여유를 두세요. 🌡️ 출발 13°C → 결승 예상 18°C 네거티브 스플릿보다 이븐 페이스를 권장합니다. 💨 남서풍 7km/h — 후반 코스 맞바람 구간 주의

RAG 아키텍처

▶ 데이터 축적 단계 사용자 A 춘천 / 13°C / 습도 95% / 3:56:17 사용자 B 춘천 / 13°C / 습도 92% / 4:12:33 ...수백 케이스 축적 ▶ RAG 검색 단계 새 사용자 → 춘천 마라톤 예상 14°C / 88% ↓ 비슷한 날씨 조건 pgvector 유사 검색 ↓ 실제 데이터 기반 페이스 전략 + 요약 생성 ▶ 캐싱 전략 (AI 비용 최소화) 기온 5°C 구간 · 습도 20% 구간 · 바람 3단계 → 동일 조건 구간 캐시 반환

조직 계층

1차 기수 (generation) → 1기, 2기, 3기... 2차 지역 (region) → 반포·연대·인천·군포 3차 조 (group) → A조/B조... (5~15명) 4차 등급 (grade) → A/B/C 자동 매칭 5차 훈련그룹 → S/1~7조 (선택) A조 → 120km / B조 → 100km / C조 → 80km

러닝 이미지 파싱 플로우

1

2

3
Draft 저장createDraft() → is_confirmed=false INSERT
4
사용자 확정결과 확인·수정 → POST /running-logs/{id}/confirm
5
